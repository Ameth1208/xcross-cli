The easiest way to build Flutter apps

XCross CLI gives you a beautiful, keyboard-driven terminal experience for Flutter development on Windows and Linux. One-line install, guided setup, xcross integration.

One-line install

Get up and running in seconds with a single command. No admin rights required.

Interactive menu

Bilingual

Guided installers for Swift, xcross, SDK import and Flutter precache.
