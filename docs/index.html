Simple 4-Step Pipeline

How it works

Four clean commands from empty terminal to iPhone running your Flutter app.

01

Install

One-line installer initializes the global xcm command in your user PATH.

irm ... | iex
02

Doctor

Verify Swift, xcross, iTunes/RSD drivers, and Flutter environment health.

xcm doctor
03

Link Project

Target your existing Flutter app folder and configure bundle identifier.

xcm project set .
04

Run on iPhone

Builds, signs, installs, and launches on your iPhone with live debugging.

xcm run --usb

Frequently Asked Questions

Everything you need to know.

Common questions about running Flutter iOS apps from Windows & Linux.

Do I need a Mac, macOS virtual machine, or cloud build server?

No! XCross CLI and the underlying xcross engine compile, sign, and deploy directly on your host PC (Windows or Linux). There are no cloud subscriptions, no remote macOS instances, and zero virtual machines required.

Do I need a paid Apple Developer account ($99/yr)?

No. You can sign in using a regular, free personal Apple ID. Free developer provisioning allows you to deploy and debug your app directly on your physical iPhone with 7-day renewable profiles.

How does Stateful Hot Reload work without Xcode?

XCross CLI establishes a high-speed Remote Service Discovery (RSD) tunnel over USB or Wi-Fi. The standard Flutter toolchain connects to the Dart VM runtime directly over this localhost tunnel, allowing instant sub-second hot reload and debugging just like on macOS.

Does the global xcm command require Administrator privileges?

No. The one-line installer copies scripts to your user directory (%LOCALAPPDATA%\Programs\XCrossCLI on Windows or ~/.local/bin on Linux) and adjusts your user-level PATH without prompting for UAC or sudo rights.

Can I switch between English and Spanish?

Yes! XCross CLI is completely bilingual. You can switch anytime using xcm language es or xcm language en, or simply press `L` in the interactive menu.
